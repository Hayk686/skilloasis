     1→# Lumina — Worklog
     2→
     3→## Project Overview
     4→Lumina — бесплатная AI-обучающая платформа. Учись чему угодно с AI-наставником.
     5→Стек: Next.js 16 (App Router), TypeScript, Tailwind 4, shadcn/ui, Framer Motion, Zustand, Prisma (SQLite), z-ai-web-dev-sdk (LLM).
     6→
     7→## Architecture
     8→- Single user-visible route: `/` (src/app/page.tsx) — client-side view switching via Zustand `useNav`.
     9→- Local anonymous user via cookie `lumina_uid` (no signup — keeps platform free).
    10→- AI backend: `src/lib/ai.ts` wraps z-ai-web-dev-sdk for tutor chat, lesson/quiz/flashcard/path/daily generation.
    11→- Gamification: `src/lib/gamify.ts` (server) + `src/lib/gamify-client.ts` (client-safe pure helpers).
    12→- DB schema: User, Progress, Achievement, ChatSession, ChatMessage, Flashcard, LessonView.
    13→
    14→## Design System (MANDATORY for all views)
    15→- Dark cosmic theme (default), violet/fuchsia/pink gradients. **NO indigo/blue as primary.**
    16→- Colors via Tailwind vars: `bg-background`, `text-foreground`, `bg-card`, `text-muted-foreground`, `bg-primary`, `text-primary`, `border-border`.
    17→- Gradient utility classes already in globals.css: `text-gradient`, `text-gradient-warm`, `glass`, `glass-strong`, `glow-primary`, `bg-grid`, `bg-dots`, `mask-radial`.
    18→- Animations: `animate-aurora`, `animate-float`, `animate-pulse-glow`, `animate-shimmer`, `animate-gradient-x`, `animate-spin-slow`, `dot-typing`.
    19→- Prose styling for AI markdown: `.prose-ai` class.
    20→- Shared UI blocks: `src/components/ui-blocks.tsx` exports `PageSection`, `SectionHeader`, `GlassCard`, `LoadingState`, `EmptyState`, `StaggerGroup`, `StaggerItem`, `Pill`, `GradientButton`.
    21→- Aurora bg: `AuroraBackground`, `Particles` from `@/components/aurora`.
    22→- Dynamic lucide icon: `DynIcon` from `@/components/dyn-icon` (name prop = lucide icon string).
    23→- shadcn components available in `src/components/ui/*` (button, card, input, textarea, dialog, tabs, progress, badge, tooltip, scroll-area, etc.).
    24→- Use `toast` from `sonner` for notifications.
    25→- Use `framer-motion` for animations (motion.div etc.).

    36→## API Contracts
    37→- `POST /api/chat` `{message, subject, sessionId?, history?}` → `{reply, sessionId, xp, level}`
    38→- `GET /api/chat` → `{sessions:[{id,subject,title,updatedAt,_count:{messages}}]}`
    39→- `GET /api/chat/[sessionId]` → `{session:{id,subject,title,messages:[{role,content}]}}`
    40→- `DELETE /api/chat/[sessionId]`
    41→- `POST /api/lesson` `{topic, subject, level?}` → `{lesson:{title,emoji,summary,durationMin,difficulty,blocks:[...],keyTakeaways,nextTopic}, xp, level}`
    42→- `POST /api/quiz` `{topic, subject, count?, level?}` → `{questions:[{id,question,options[4],correctIndex,explanation,difficulty}], topic, subject}`
    43→- `PUT /api/quiz` `{subject, topic, total, correct}` → `{correct, total, xpGain, xp, level}`
    44→- `POST /api/flashcards` `{topic, subject, count?}` → `{cards:[{front,back}], xp, level}`
    45→- `GET /api/flashcards?subject=&limit=` → `{cards:[{id,subject,front,back,easeFactor,interval,repetitions,dueAt}]}`
    46→- `PATCH /api/flashcards/[id]` `{quality:'again'|'hard'|'good'|'easy'}` → `{card, xp, level}`
    47→- `DELETE /api/flashcards/[id]`
    48→- `POST /api/explain` `{concept}` → `{text, concept}`
    49→- `GET /api/daily` → `{challenge:{date,subject,emoji,title,prompt,hint,xpReward}}`
    50→- `POST /api/daily` `{xpReward}` → `{ok, xp, level, xpGain}`
    51→- `POST /api/paths` `{goal, level?}` → `{path:{goal,emoji,duration,level,steps:[{title,description}]}}`
    52→- `GET /api/progress` → `{progress, achievements, bySubject, byKind, byDay}`
    53→- `GET /api/user` → `{user:{id,name,xp,level,streak,achievements,counts,computedLevel}}`
